# Supreme Hero Flicks · 已上传视频的标题、封面与定时发布

本版管理**已经上传到 YouTube 的视频**：扫描频道 → 按剧名匹配 → 读取现有说明 → 展示修改前后审核单 → 你批准 → 应用英语标题、封面、说明末行代码及定时公开。不重新上传视频，不需要本地视频或说明文件。

包含 **2026 年 10 月 22—25 日**的 8 条排片、24 个英语标题、8 张 AI 封面，无需 OpenAI API Key。后续批次在 ChatGPT 对话中生成后再导入。

## 下载与启动

1. 绿色 **Code → Download ZIP**，完整解压。
2. 安装 Python 3.10+（包含 Tcl/Tk；Windows 勾选 Add Python to PATH）。
3. Windows 双击 `start_windows.bat`；Mac/Linux 运行 `bash start_mac_linux.sh`。
4. 点击“导入内置素材”，配置并完成“YouTube 官方授权”。
5. 点击“扫描频道已上传视频”，选择剧集并核实匹配视频。
6. 生成审核单 → 阅读前后对照 → 明确批准 → 应用到已上传视频并定时公开。

多条匹配或无匹配不自动决定，可以在下拉框选择，或直接输入视频 ID。不会根据题材猜测英语标题对应的中文剧名。默认仅处理私密视频；YouTube 要求定时发布的视频从未公开过，程序不能从 API 完整判断历史，平台可能拒绝。

## 修改规则

- 现有说明从 YouTube 直接读取，原文保留，只在最后一行追加对应剧集代码；已有相同末行代码不重复添加。
- 审核单包含准确视频 ID/链接、原/新标题、原/新说明、封面、原/新发布时间。仅对明确批准的版本执行。
- 保留现有标签、分类、语言与可写状态字段，不修改频道说明，不创建、上传或删除视频。
- 北京时间 17:00 / 21:00，过期排期不自动顺延。线上内容或封面在审核后变化时停止，重新审核。

详情与 Google OAuth 步骤见 [使用说明.md](使用说明.md)。已完成 13 项离线/模拟测试；真实 YouTube 读取和修改、桌面交互未实测。标题和封面依据大纲，未使用实时热门频道数据。

仓库不包含原始资源表、网盘链接、提取码或授权令牌。扫描到的私密视频信息只保存在被 Git 忽略的本机 local_work/ 中。
