# Supreme Hero Flicks · 标题封面与定时上传

本版从 **2026 年 10 月 22 日**开始，包含 22—25 日的 **8 条排片、24 个英语标题、8 张 AI 封面**。标题和封面已制作完成，不需要 OpenAI API Key。后续新批次仍需在 ChatGPT 对话中生成后导入。

## 下载与启动

1. 点击本页面上方绿色 **Code** 按钮，再点 **Download ZIP**。
2. 将 ZIP 完整解压到电脑。
3. 安装 Python 3.10 或更高版本（Windows 选中 Add Python to PATH 和 Tcl/Tk）。
4. Windows 双击 `start_windows.bat`；Mac/Linux 在终端运行 `bash start_mac_linux.sh`。
5. 在程序中点击“导入内置素材”。也可双击 `assets/index.html` 离线浏览标题和封面。

首次启动会下载依赖。若没有 tkinter，请使用带 Tk 的官方 Python 安装版或系统 python3-tk。

## 审核与发布

选择剧集、标题、本地完整视频和现有说明的 UTF-8 文本文件；生成修改前后审核单，由你明确审核批准后才上传。视频说明原文保留，只在最后一行追加剧集代码。按北京时间 17:00 / 21:00 定时公开；过期排期需明确指定新时间并重新批准。

上传需要 Google Cloud 的 YouTube Data API v3 桌面 OAuth 客户端（本地保存为 `client_secret.json`），以及频道管理账号授权。具体步骤见 [使用说明.md](使用说明.md)。不修改频道说明或其他视频。

## 数据与验证范围

仅包含选定排片快照和生成素材，未包含原始资源表、网盘链接、提取码、视频、OAuth 文件或令牌。AI 封面是剧情概念图，非实际演员剧照。本批未结合实时热门频道数据。已验证素材导入和 7 项测试（含模拟上传）；真实 YouTube 上传和桌面交互尚未实测。

更新素材、说明或排期后需要重新审核。不要把凭据、本地运行状态或私人资源表提交到仓库。
