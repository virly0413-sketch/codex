# Supreme Hero Flicks · 已上传视频的标题、封面与定时发布

本版管理**已经上传到 YouTube 的视频**：扫描频道 → 按剧名匹配 → 读取现有说明 → 展示修改前后审核单 → 你批准 → 应用英语标题、封面、说明末行代码及定时公开。不重新上传视频，不需要本地视频或说明文件。

包含 **2026 年 10 月 22—25 日**的 8 条排片、24 个英语标题、8 张 AI 封面，无需 OpenAI API Key。后续批次在 ChatGPT 对话中生成后再导入。

## 下载与启动

1. 绿色 **Code → Download ZIP**，完整解压。
2. 安装 Python 3.10+（包含 Tcl/Tk；Windows 勾选 Add Python to PATH）。
3. Windows 双击 `start_windows.bat`；Mac/Linux 运行 `bash start_mac_linux.sh`。
4. 点击“导入内置素材”，配置并完成“YouTube 官方授权”。
5. 点击“扫描频道已上传视频”，选择剧集并核实匹配视频。
6. 生成审核单 → 阅读前后对照 → 明确批准 → 应用到已上传视频并定时公开。

多条匹配或无匹配不自动决定，可以在下拉框选择，或直接输入视频 ID。不会根据题材猜测英语标题对应的中文剧名。默认仅处理私密视频；YouTube 要求定时发布的视频从未公开过，程序不能从 API 完整判断历史，平台可能拒绝。

## 修改规则

- 现有说明从 YouTube 直接读取，原文保留，只在最后一行追加对应剧集代码；已有相同末行代码不重复添加。
- 审核单包含准确视频 ID/链接、原/新标题、原/新说明、封面、原/新发布时间。仅对明确批准的版本执行。
- 保留现有标签、分类、语言与可写状态字段，不修改频道说明，不创建、上传或删除视频。
- 北京时间 17:00 / 21:00，过期排期不自动顺延。线上内容或封面在审核后变化时停止，重新审核。

详情与 Google OAuth 步骤见 [使用说明.md](使用说明.md)。已完成 16 项离线/模拟测试；真实 YouTube 读取和修改、桌面交互未实测。标题和封面依据大纲，未使用实时热门频道数据。

仓库不包含原始资源表、网盘链接、提取码或授权令牌。扫描到的私密视频信息只保存在被 Git 忽略的本机 local_work/ 中。


## Windows 连接超时 / WinError 10060

本机浏览器能访问 YouTube，不代表 Python 已走同一个代理。本版 config.json 已按本次提供的本机代理预设 http://127.0.0.1:7897，连接超时 30 秒；示例配置保留空代理以便其他机器自行设置。

1. 保持 VPN/代理客户端运行，确认本机 HTTP 或 Mixed 代理端口为 7897。
2. 在程序顶部检查“程序代理”为 http://127.0.0.1:7897，点“保存网络设置”。
3. 点击“诊断连接”，读取 Google OAuth、YouTube API 和程序传输层的结果。诊断不读取视频、不修改任何内容，也不显示令牌。
4. 收到 HTTP 400/401/403 等响应只表示收到网络响应，不证明账号授权或配额正常。扫描时的具体 HTTP 401/403 仍需排查授权、API 启用和配额；超时则继续检查代理端口、规则和系统防火墙。
5. 诊断后再次点击“扫描频道已上传视频”。日志实时显示正在核对频道、列表页数和视频详情批次。

如果 7897 是纯 SOCKS5 端口，可将代理改为 socks5h://127.0.0.1:7897；协议应与代理客户端提供的端口类型一致。端口未运行、协议不匹配或代理规则拒绝 Google 时，单纯延长超时不能解决。

本版让 OAuth 令牌刷新和 YouTube API 使用一致的显式代理；保持 TLS 验证。只读 API 请求有有限重试，实际修改不自动重试。测试覆盖配置与传输设置，但无法代替在你电脑上实际诊断代理。

更新时请备份旧目录，解压到新目录，把自己本机的 client_secret.json 与 token.json 复制到新目录。不要把这两个文件上传到 GitHub。config.json 的网络设置可在界面修改，local_work 中已批准记录如需迁移请备份；已变更的审核单仍须重新批准。
