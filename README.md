## 启动与发布

1. 绿色 Code → Download ZIP，完整解压；安装 Python 3.10+（包含 Tk）。
2. Windows 双击 start_windows.bat；Mac/Linux 运行 bash start_mac_linux.sh。
3. 放入自己的 client_secret.json，点击“切换授权频道”，选择管理俄语目标频道的账号/品牌频道。若使用新的测试账号，需在 Google Auth Platform 的测试用户中添加该邮箱。
4. 本机代理预设 http://127.0.0.1:7897，可在界面修改并点击“诊断连接”。
5. 排片和素材准备好后，加载素材、扫描已有私密视频，选择视频、标题、封面、代码和时间，**点击一次“发布”即可执行，无需单独审核/批准**。

现有视频说明从 YouTube 读取并保留原文，仅在最后一行追加剧集代码。不重新上传视频，不修改频道说明。已公开视频、匹配歧义、频道不符或不确定执行状态仍会停止；定时发布需平台支持的私密且从未公开视频。

修改前保留可见选择，点击发布即授权执行这一组内容。后台保存快照用于防重复与差异诊断，不要求额外人工批准。核对线上结果按钮只读，不重复提交修改。

详细授权、代理和故障处理见 [使用说明.md](使用说明.md)。已通过 25 项离线/模拟测试，包含单击发布防重复、频道隔离；真实俄语频道访问与修改尚未验证。不会在聊天中直接执行频道修改。
